# Audit — l'atelier contre la checklist officielle Opus 5.5 (2026-09-24)

Demande de Gabriel : vérifier que les règles du guide officiel
(platform.claude.com, prompting-claude-opus-5-5 + migration-guide) sont
appliquées dans la création de prompts. Lecture seule, rien corrigé.
Source relue : les 16 points de la checklist sont confirmés par le guide
(C16 : trois classifieurs nouveaux, pas un — bio, cyber, extraction de raisonnement).

## Cause racine
La méthode Opus 5.5 (`src/opus55.js:4-5`, DECISIONS § 31) est tirée du billet
d'Addy Osmani sur claude.dev, pas du guide de prompting ni du guide de migration. D'où une méthode
centrée sur le texte du prompt, muette sur les réglages et le harnais, alors que
le guide officiel dit que c'est là qu'est l'essentiel du gain.

## Appliqué
- Réflexion jamais coupée sur Opus 5.5, marge de jetons ajoutée (`api.js:62,105-109`).
- Flux lu par type de bloc, seuls les `text_delta` (`api.js:212`).
- Effort explicite par rôle (`meta.js:142-146`, `api.js:95` → `output_config.effort`).
- Aucun « réfléchis bien », aucun « montre ton raisonnement » dans les méta-prompts ;
  la méthode les interdit dans les prompts produits (`opus55.js:340-341`, oracle).
- Pas de « tiens pour acquis » (correct pour de l'agentique).
- Frontend : les 5 motifs du guide nommés (`opus55.js:139-145`).
- Pas de « finis en N minutes » écrit ; timeout dur propre côté atelier (`api.js:71`).

## Écarts (par impact)
1. C14 texte collé NON appliqué : l'idée est concaténée brute après « IDÉE : »
   (`App.jsx:473-474`, `opus55.js:515`, `meta.js:243`, `Atelier-Prompting/atelier.mjs:128`),
   le prompt jugé entre `---` (`meta.js:174`). Aucune note système.
2. Idée maîtresse : l'utilisateur repart avec un prompt et aucun réglage
   (effort, relances du harnais, display "updates").
3. C1/C2 : `high` (rédaction, juge) jamais mesuré contre `medium` — le banc § 31
   comparait des modèles ; juge du banc en `max` par défaut (`banc-opus55.mjs:40`).
   Message trompeur quand la réflexion mange le budget : « Baisse la limite de
   caractères » (`api.js:237`).
4. C3 : effort racine medium (`App.jsx:481`) puis high (`App.jsx:396`) dans la même
   conversation ; aucun `cache_control` nulle part → méta-prompt refacturé à chaque
   tentative (jusqu'à 6, `generate.js:11`).
5. C9/C10/C11/C12 (ce que la méthode fait écrire) : pas de « reprends Fini veut dire
   avant ton compte rendu » ; anti-arrêt aussi imposé pour l'app Claude (humain dans
   la boucle, `opus55.js:290`) ; ni `display: "updates"` ni rappel après ~5 étapes
   muettes ; aucune phrase « explore largement ».
6. Boris (`meta.js:63`) interdit « ne t'arrête pas » pour un agent 24/7 — contraire au
   guide SI la cible est Opus 5.5. Assumé (§ 31), à trancher.
7. Terminal : `atelier.mjs:5` dit « même juge », mais n'applique pas `ROLES.juge`
   (aucun effort lu).
